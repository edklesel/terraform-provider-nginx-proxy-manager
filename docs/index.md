# nginxproxymanager

The Nginx Proxy Manager provider is used to manage instances of [Nginx Proxy Manager](https://nginxproxymanager.com) via the API.

**This provider has been developed as part of a learning project, and is not suitable for production purposes.**

## Example Usage 

```terraform
provider "nginxproxymanager" {
  host     = "http://localhost:81"
  username = "admin@example.com"
  password = "changeme"
  secure   = false
}
```
